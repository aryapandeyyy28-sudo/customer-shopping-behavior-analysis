# Customer Shopping Behavior Analysis

This repository contains an end-to-end data analysis project focused on understanding consumer shopping patterns, purchasing habits, and revenue drivers using Python, SQL, and Power BI.

## Overview
The goal of this project is to analyze retail transaction data to extract actionable business insights regarding customer demographics, product category performance, and seasonal trends.

## Tools Used
* Python (Pandas, Matplotlib, Seaborn) for data cleaning and exploratory analysis
* SQL for querying data, aggregations, and business metrics
* Power BI for data modeling and interactive dashboard visualization

## Project Structure
* data/ - Contains the dataset used for analysis
* notebooks/ - Jupyter notebooks covering data exploration and insights
* sql/ - SQL queries used for business metric extraction
* dashboards/ - Power BI report file (.pbix)

## Key Questions Explored
* Which demographic segments generate the highest sales volume?
* How do discounts and promo codes influence overall purchase amounts?
* Which product categories perform best across different seasons?
* What are the most preferred payment methods and shipping types among repeat buyers?

## Setup & Usage
1. Clone the repository:
   git clone https://github.com/aryapandeyyy28-sudo/customer-shopping-behavior-analysis.git
2. Run the Jupyter Notebook to review the exploratory data analysis.
3. Execute the SQL scripts in your preferred database to generate summary tables.
4. Open the .pbix file in Power BI Desktop to interact with the dashboard.
